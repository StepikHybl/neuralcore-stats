Privacy policy

NeuralCore Stats · last updated 8 November 2026

What the app accesses

With the channel owner's permission, NeuralCore Stats uses Google OAuth with two read-only scopes: YouTube Data API (youtube.readonly) and YouTube Analytics API (yt-analytics.readonly). It reads the channel's public video data (titles, view, like and comment counts) and the channel's own analytics (watch time, average view percentage, audience retention, traffic sources, subscriber changes).

How the data is used and stored

The data is saved as files on the channel owner's own computer, only to review the channel's performance. It is not sold, not shared with third parties, not used for advertising and not uploaded anywhere. The sign-in token is stored locally on the same computer.

Who uses the app

The app is used only by the owner of the NeuralCore channel. It is not offered to other users.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions; deleting the local files removes all stored data.

Google API Services

NeuralCore Stats' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses the YouTube API Services and follows the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions: the e-mail address of the NeuralCore channel owner listed on the Google sign-in screen.
